# Briefing S01-B09: editor fixes and shared packages for theclient

Track: theserver, Season S01. Repo `github.com/cyb3rgun/theserver`, `main` at `ebe85f5` or later. Implementer: CC. Architect: Mausi.

Two purposes: the three forward fixes from B08, and moving the packages theclient needs into `pkg/` with a tag, so the client repository can import them.

## 1. Decisions

- **`pkg/` is the public surface of theserver.** `pkg/protocol` (device link types and codec), `pkg/scenario` (manifest, validation, rules engine), `pkg/journal` (the device side journal with sequence, epoch, unacked, ack, currently inside `internal/simtarget`). Everything else stays internal. Public means: theclient and thefirmware tooling may import it; the API is versioned by tags. D-048.
- **Tags.** `v0.1.0` after this pass; theclient pins it. Later passes bump the tag when `pkg/` changes. D-049.
- **Draft locking.** A draft carries `locked_by`, `locked_at`; opening the editor takes the lock for the session, refreshes it every minute, releases on leave; another admin sees who holds it and can take over with a confirmation that logs both names. D-050.
- **Undo.** The editor keeps the last 50 manifest states in the browser and the server keeps the last 20 patches per draft in `scenario_draft_history`; undo and redo in the browser, "restore version" from the history on the server. D-051.
