## Read this first

- **theserver always uses the newest stable Go release (D-001).** `go.mod` says `go 1.27.1`. The installed toolchain is `go1.27.0` from winget; with `GOTOOLCHAIN=auto` the go command fetched `go1.27.1` on first use in the module, and `go version` there reports `go version go1.27.1 windows/amd64`. When a newer stable release ships, raise the go directive and record it in D-001.
- **Do not set `GOTOOLCHAIN=local` in this module.** With the installed go1.27.0 it refuses: `go: go.mod requires go >= 1.27.1 (running go 1.27.0; GOTOOLCHAIN=local)`.
- **Versions come from Go, never from memory.** `go get <module>@latest`, then copy the version from `go.mod` into `docs/decisions.md`. The only dependency is `github.com/BurntSushi/toml v1.6.0`.
- **The dash check caught its own author.** Writing the escape sequence for U+2014 through the editor tool put the literal character into `tools/check_dashes.py`. The script now builds both characters with `chr(0x2014)` and `chr(0x2013)` and is pure ASCII. Any file that needs those code points does the same, and the check runs before every commit.
- **Every pass ends with its own `docs(handover)` commit (D-008).** Handovers follow the THESITE season handover shape (D-007).

## Choices made inside the briefing, to confirm

1. TOML keys are snake case (`listen_addr`, `data_dir`); environment names are as briefed (`THESERVER_SERVER_LISTENADDR`, `THESERVER_SERVER_DATADIR`, `THESERVER_LOG_LEVEL`, `THESERVER_LOG_FORMAT`).
2. `--config` has no default. "TOML file if present" is read as "if one is named"; a named file that does not exist is an error, not silently skipped.
3. An unknown key in the file is an error, so a typo does not fall back to a default.
4. `WriteDefault` never overwrites an existing file.
5. `log.format` has no flag, because the briefing's flag list has none.
6. `internal/version` went into `build(go): initialize module`, so that commit holds a package that compiles.
7. `tools/check_dashes.py` was written before the first commit and left untracked until its own commit, so the check could run before every commit as required.
8. The server listens on `:8443`, all interfaces, as the default says. Windows Defender Firewall may ask about `dist\theserver.exe` on first start; the loopback check works either way.

## Traps that survived

1. Git Bash mangles quotes inside `cmd //c '...'`: the cross compile line failed with `invalid value "\"-s" for flag -ldflags`. Run cmd syntax from a real cmd window, or pipe the line into `cmd` on stdin. The briefed line itself is correct.
2. Processes started from the Claude Code shell inherit "ignore Ctrl+C". The first CTRL_C_EVENT never reached the server, which had to be killed after 10 seconds. It worked once the parent called `SetConsoleCtrlHandler(NULL, FALSE)` before starting the server. Ctrl+C in an ordinary console window was not tried.
3. `set GOOS=linux&` stays set in that cmd window; the next `go build` there builds Linux again.
